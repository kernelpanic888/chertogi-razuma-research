# Паспорт IF-BS-22F-F8A

## Точка маршрута

`IF-BS-22F-F8A / EXPLICIT SUMMABLE TRANSLATIONS -> NONTRIVIAL F7 WITNESS`

## Вход

- `s_n = 1 - 2^(-n)`.
- `delta_n = s_(n+1) - s_n`.
- `T_n(x) = x + delta_n` на `Real`.

## Выход

- `F_n(x) = x + s_n` для каждого конечного префикса.
- `F_n -> (x ↦ x+1)` равномерно на всём `Real`.
- `F_n^(-1) -> (x ↦ x-1)` равномерно на всём `Real`.
- `Lip(F_n)=Lip(F_n^(-1))=1`.
- Предельный homeomorphism точно равен переносу на единицу.
- Предельный интерфейс является actual frontier, а точные и вычислимые носители сходятся к нему.

## Проверяемая формула

`sum_(k<n) delta_k = s_n -> 1`

`F_n(x)=x+s_n -> H_infinity(x)=x+1`

`H_infinity^(-1)(x)=x-1`.

## Красная граница

Перенос имеет глобальную поддержку. Этот слой доказывает невакуумность F7, но ещё не реализует локальную деформацию границы.

## Русская вычитка

Бесконечный маршрут может состоять из всё меньших ненулевых шагов и при этом иметь точный обратимый предел. В данном свидетеле каждый шаг сохраняет все расстояния, накопленное движение телескопируется, а пределом становится ненулевой перенос всего пространства на единицу.
