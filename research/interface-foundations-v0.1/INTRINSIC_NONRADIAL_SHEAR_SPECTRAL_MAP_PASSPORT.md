# Паспорт F8C6B. Точная двухсторонняя спектральная камера

## Статус

Завершено локально. Прямая и обратная минимальные глобальные константы карты формализованы. Публичная публикация среза выполняется только по отдельной команде.

## Точные константы

```text
λ→(a)=1+a+a²+a√(a²+2a+2)
C→(a)=√λ→(a)
```

```text
λ←(a)=[1-a+a²+a√(a²-2a+2)]/(1-a)²
C←(a)=√λ←(a)
```

Область:

```text
a≥0            для прямой стороны
0≤a<1          для двухсторонней камеры
```

## Формальный результат

```text
d(Sₐp,Sₐq) ≤ C→(a)d(p,q)
d(p,q) ≤ C←(a)d(Sₐp,Sₐq)
```

Обе константы минимальны среди всех неотрицательных глобальных коэффициентов соответствующего направления.

## Свидетели точности

- Прямая сторона: отрицательные хорды `(-tB,-tA)`, `t→0⁺`.
- Обратная сторона: положительные хорды `(tx,ty)`, `t→0⁺`.
- В обоих случаях точки остаются внутри квадратного носителя при достаточно малом `t`.

## Красная граница

Результат математический и модельный. Физическая калибровка амплитуды `a`, связь с измеряемыми полями и физический статус PlanckTouch не заявлены.
