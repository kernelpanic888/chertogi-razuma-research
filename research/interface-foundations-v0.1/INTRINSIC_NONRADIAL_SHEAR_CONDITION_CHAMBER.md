# F8C7. Коэффициент состояния и сертификат амплитуды

## Задача

F8C6B дал точные минимальные глобальные константы прямого и обратного искажения карты `Sₐ`. F8C7 превращает их из описания геометрии в проверяемый параметрический инструмент.

## Точные стороны

```text
C→(a)=√[1+a+a²+a√(a²+2a+2)]
```

```text
C←(a)=√{[1-a+a²+a√(a²-2a+2)]/(1-a)²}
```

Область двухсторонней камеры:

```text
0 ≤ a < 1.
```

## Строгая монотонность

Lean доказывает:

```text
0 ≤ a < b
  ⇒ C→(a) < C→(b)
```

и

```text
0 ≤ a < b < 1
  ⇒ C←(a) < C←(b).
```

Поэтому равенство точных констант возможно только при равенстве амплитуд:

```text
C→(a)=C→(b) ⇒ a=b
C←(a)=C←(b) ⇒ a=b.
```

## Коэффициент состояния

```text
K(a)=C→(a)C←(a).
```

Формально доказано:

```text
K(0)=1,
K(a)≥1,
0≤a<b<1 ⇒ K(a)<K(b).
```

Следовательно:

```text
K(a)=K(b) ⇒ a=b.
```

Внутри этой модели точное значение `K` однозначно определяет амплитуду.

## Наблюдаемое искажение

Пусть `F` и `B` являются проверенными глобальными коэффициентами:

```text
d(Sₐp,Sₐq) ≤ F·d(p,q)
d(p,q) ≤ B·d(Sₐp,Sₐq).
```

Тогда:

```text
C→(a) ≤ F,
C←(a) ≤ B.
```

И наоборот, эти два неравенства достаточны для соответствующих глобальных оценок. Это формальная эквивалентность, а не односторонняя эвристика.

## Явный сертификат амплитуды

Из осевых нижних оценок выводится:

```text
a ≤ F-1
```

и

```text
a ≤ (B-1)/B.
```

Итоговый проверяемый сертификат:

```text
a ≤ min(F-1, (B-1)/B).
```

Он может быть слабее численного обращения точных функций `C→` и `C←`, но является явным, замкнутым и полностью доказанным.

## Геометрия допустимых значений

Определено множество амплитуд, совместимых с наблюдениями:

```text
Feasible(F,B,a) :⇔
  0≤a<1 ∧ C→(a)≤F ∧ C←(a)≤B.
```

Lean доказывает его замкнутость вниз:

```text
Feasible(F,B,a) ∧ 0≤b≤a
  ⇒ Feasible(F,B,b).
```

Таким образом, совместимые значения образуют начальную параметрическую камеру, а не разрозненное множество.

## Исключение кандидатов

Если

```text
F < C→(b),
```

то фактическая амплитуда обязана удовлетворять `a<b`. Аналогичный критерий доказан для обратной стороны:

```text
B < C←(b) ⇒ a<b.
```

## Красная граница

`F` и `B` должны быть обоснованными глобальными оценками. Конечный набор измеренных хорд сам по себе не доказывает глобальную верхнюю границу без дополнительных предпосылок о покрытии, регулярности и ошибке измерения. Физическая калибровка `a` по-прежнему не заявлена.
