# F8C8. Конечные хордовые свидетели и шумовая полоса

## Задача

F8C7 принимает `F` и `B` как уже обоснованные глобальные коэффициенты. Конечный эксперимент устроен иначе: он видит лишь несколько хорд и не может автоматически заменить глобальный максимум.

F8C8 формализует честную роль конечной выборки:

```text
конечные хорды дают нижние свидетельства,
а не глобальные верхние гарантии.
```

## Хордовое чтение

Каждая запись содержит:

```text
(p,q,ℓ)
```

где `p,q` являются точками, а `ℓ` — подтверждённая нижняя оценка отношения расстояний.

Прямая валидность:

```text
p≠q
ℓ≥0
ℓ·d(p,q) ≤ d(Sₐp,Sₐq).
```

Обратная валидность:

```text
Sₐp≠Sₐq
ℓ≥0
ℓ·d(Sₐp,Sₐq) ≤ d(p,q).
```

## Конечный максимум

Для списка чтений рекурсивно определяется:

```text
L(sample)=max(0,ℓ₁,…,ℓₙ).
```

Lean доказывает:

```text
L→(sample) ≤ C→(a)
```

для любой валидной прямой выборки и

```text
L←(sample) ≤ C←(a)
```

для любой валидной обратной выборки.

Это sound нижние границы точных глобальных констант.

## Абсолютная погрешность

Пусть измерены:

```text
mᵢₙ, mₒᵤₜ
```

с абсолютными ошибками

```text
εᵢₙ, εₒᵤₜ.
```

Консервативное прямое чтение:

```text
L→noise =
  (mₒᵤₜ-εₒᵤₜ)/(mᵢₙ+εᵢₙ).
```

При положительном знаменателе и `mₒᵤₜ≥εₒᵤₜ`:

```text
0≤L→noise
L→noise·dᵢₙ ≤ dₒᵤₜ.
```

Консервативное обратное чтение:

```text
L←noise =
  (mᵢₙ-εᵢₙ)/(mₒᵤₜ+εₒᵤₜ).
```

При положительном знаменателе и `mᵢₙ≥εᵢₙ`:

```text
0≤L←noise
L←noise·dₒᵤₜ ≤ dᵢₙ.
```

Обе формулы выведены непосредственно из абсолютных полос ошибок.

## Исключение слишком малой амплитуды

Если для кандидата `b`

```text
C→(b) < L→(sample),
```

то:

```text
b < a.
```

Аналогично:

```text
C←(b) < L←(sample)
  ⇒ b<a.
```

Конечная выборка тем самым исключает слишком малые амплитуды.

## Двухсторонний интервал

Пусть конечная выборка исключила кандидата `b`, а отдельно обоснованные глобальные коэффициенты `F,B` прошли контракт F8C7. Тогда:

```text
b < a ≤ min(F-1,(B-1)/B).
```

Левая сторона интервала приходит от конечного свидетеля. Правая сторона приходит от глобального сертификата. Эти роли не смешиваются.

## Красная граница

Максимум конечной выборки остаётся нижней границей глобальной константы. Чтобы превратить конечную сетку в глобальную верхнюю оценку, нужны дополнительные данные: радиус покрытия, модуль регулярности функции искажения и учёт ошибок. Это отдельный следующий срез.
