# Паспорт IF-BS-22F-F6

## Точка маршрута

`IF-BS-22F-F6 / UNIFORM-CAUCHY PREFIX -> ONE COMMON COMPACT CARRIER`

## Вход

- Полное псевдометрическое пространство `X`.
- Компактный непустой исходный интерфейс `I` из `ComputableBoundaryModel`.
- Последовательность controlled-самопереносов и её префиксные отображения `F_n`.
- Равномерная Cauchy-сходимость `F_n` на `I`.
- Для вычислимого слоя: ограниченность префиксных произведений `P_n <= C` из F5.

## Выход

- Существует `F_infinity` с равномерной сходимостью `F_n -> F_infinity` на `I`.
- `F_infinity` непрерывно на `I`.
- `I_infinity = F_infinity[I]` непуст и компактен.
- `d_H(F_n[I], I_infinity) -> 0`.
- `d_H(K_n^(n), I_infinity) -> 0` при условии F5.

## Проверяемая формула

`UniformCauchy(F_n|I) + Complete(X) => exists F_infinity, I_infinity = F_infinity[I]`

`d_H(F_n[I], I_infinity) -> 0`

`P_n <= C => d_H(K_n^(n), I_infinity) -> 0`

## Красная граница

Компактный общий носитель ещё не назван actual frontier предельной области. Односторонняя равномерная сходимость не гарантирует, что `F_infinity` инъективно, обратимо или открыто.

## Русская вычитка

Если накопленные преобразования становятся равномерно неразличимыми на всём компактном интерфейсе, полнота пространства не позволяет маршруту оборваться: возникает единое предельное отображение и единый компактный носитель. Каждый точный префиксный интерфейс и каждый контролируемый вычислимый носитель приближаются уже не к собственной движущейся цели, а к одному и тому же пределу.

## Следующий шаг по паспорту

`IF-BS-22F-F7`: потребовать равномерно Cauchy-контроль префиксных отображений и их обратных отображений, построить взаимно обратные пределы, получить предельный homeomorphism и доказать, что общий носитель является actual frontier перенесённой предельной области.
