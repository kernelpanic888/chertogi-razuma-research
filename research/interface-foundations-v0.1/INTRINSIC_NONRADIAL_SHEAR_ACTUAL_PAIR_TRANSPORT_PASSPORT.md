# Паспорт IF-BS-22F-F8C25

## Имя

Actual-pair transport / Перенос реальной пары.

## Вход

- Точная realizable diamond-камера F8C15.
- Точный локальный касательный модуль F8C21–F8C22.
- Точная центрированная огибающая F8C24.

## Новые доказанные узлы

- Одномерное тождество `|m+h|+|m-h|=2 max(|m|,|h|)`.
- Каноническая центрированная запись каждой пары единичных направлений.
- Полная обработка совпадающего направления `k=0` и антиподального среднего `r=0`.
- Точная ширина среднего склона через две max-ветви F8C24.
- Глобальная конечнопарная оценка `|ΔΦ|<=L_tan(a)d` на всём directional diamond.

## Статус утверждения

`L_tan(a)` теперь формально является достаточным глобальным модулем. Его минимальность среди всех глобальных модулей пока не заявляется.

## Проверяемый носитель

- `formal/IntrinsicNonradialShearActualPairTransport.lean`
- `formal/IntrinsicNonradialShearActualPairTransportAudit.lean`

## Красная граница

Нужна явная допустимая последовательность конечных пар, насыщающая касательный предел. Только после неё можно доказать `IsLeast` для множества глобальных хордальных модулей.
