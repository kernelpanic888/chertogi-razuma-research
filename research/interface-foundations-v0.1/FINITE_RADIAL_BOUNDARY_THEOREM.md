# IF-BS-21: finite radial boundary theorem

## Theorem package

For every refinement parameter `m > 0`:

- every two sampled inside vertices are joined by an inside unit path;
- every two sampled outside vertices are joined by an outside unit path;
- the complete threshold-crossing edge set is an inclusion-minimal bond;
- every contour incidence state lies on a finite closed alternating traversal;
- the edge set represented by every selected contour orbit separates the two
  sides;
- every selected orbit represents every threshold-crossing edge;
- any two selected anchors therefore determine the same geometric edge set.

This is the finite single-geometric-contour theorem for the radial chamber.

## Meaning

Earlier modules proved that the contour cannot end and decomposes into closed
orbits. IF-BS-21 now excludes multiple geometric components: one orbit already
contains the complete threshold boundary, independently of its starting state.

## Red boundary

The result is exact for every finite sampled grid and for the rational edge
interpolation already defined in IF-BS-10. It does not yet state convergence of
the polygonal contour to the continuous circle in Hausdorff distance, nor a
rate for that convergence.
