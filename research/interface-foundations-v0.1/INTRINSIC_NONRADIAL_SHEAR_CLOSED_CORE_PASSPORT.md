# Паспорт F8C11. Замкнутое ядро

## Статус

Локальный постоянный срез собран. Замкнутость, компактность и существование конечных δ-сетей для прямого и обратного активных ядер доказаны.

## Контракт

```text
ρ≥0,
δ>0,
a≥0 для обратного ядра.
```

## Результат

```text
K→(ρ) closed ∧ compact,
K←(a,ρ) closed ∧ compact.
```

```text
∀δ>0,
∃ finite Γδ⊆Kcore,
∀x∈Kcore, ∃γ∈Γδ, d(x,γ)<δ.
```

Для любого значения `f` существует конечный точный список F8C9:

```text
valid ∧ coverage ∧ sample-inside.
```

При отдельном `RegularityCertificate(L)`:

```text
f(x)≤Mnoise+Lδ.
```

## Красная граница

Модуль регулярности хордового отношения возле диагонали не доказан. Компактность обеспечивает конечное покрытие, но не устраняет деление на исчезающую длину хорды.

## Следующий формальный срез

F8C12 / Десингуляризация диагонали.

1. Заменить отношение длин на непрерывную квадратичную форму приращения или доказать его направленное продолжение.
2. Выделить касательное направление хорды как отдельный параметр.
3. Доказать локальный модуль регулярности на компактном поднятом пространстве.
4. Получить конечный численный верхний сертификат через F8C9-F8C11.
5. Сравнить сертификат с точными спектральными константами F8C6B.
6. Провести независимый аудит и нарисовать камеру диагонального blow-up.
