# Паспорт F8C12. Blow-up диагонали

## Статус

Локальный постоянный срез собран. Сингулярное прямое хордовое отношение заменено непрерывным квадратом растяжения на компактной направленной камере.

## Контракт

```text
a≥0,
δ>0.
```

Для ненулевой хорды:

```text
u=(p-q)/d(p,q),
s=(κ(p)-κ(q))/d(p,q).
```

## Результат

```text
blowUp(p,q)∈S¹×[-√2,√2].
```

```text
Φₐ(u,s)=uₓ²+(uᵧ+a·s)².
```

```text
d(Sₐp,Sₐq)²=Φₐ(blowUp(p,q))d(p,q)².
```

```text
|Φₐ(z)-Φₐ(w)|≤[2+4(1+a)²]d(z,w).
```

Конечный сертификат:

```text
d(Sₐp,Sₐq)²
≤[Mnoise+(2+4(1+a)²)δ]d(p,q)².
```

## Красная граница

Направленная камера является доказанным внешним контейнером реализуемых chord blow-ups, но её точное реализуемое подмножество пока не охарактеризовано. Сертификат поэтому безопасен, но не заявлен оптимальным. Обратный blow-up остаётся отдельным обязательством.
