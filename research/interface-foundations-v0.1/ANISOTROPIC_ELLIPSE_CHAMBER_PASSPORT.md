# Паспорт IF-BS-22F-F2

## Узел

Конкретная анизотропная эллиптическая камера.

## Вход

- Проверенная радиальная камера с границей `x²+y²=2`.
- Общий controlled bi-Lipschitz transport IF-BS-22F-F1.
- Сходящееся семейство непустых компактных вычислимых носителей.

## Конструкция

- `F(x,y)=(2x,y)`.
- `F⁻¹(x,y)=(x/2,y)`.
- Прямой контроль: `||F(p)-F(q)|| <= 2||p-q||`.
- Обратный контроль: `||F⁻¹(p)-F⁻¹(q)|| <= ||p-q||`.

## Выход

- Точная граница: `x²/4+y²=2`.
- Эта граница является `frontier(F[A])`, а не только нарисованной кривой.
- Ошибка переноса: `d_H(F[K_n],F[I]) <= 2e_n`.
- Предел: `d_H(F[K_n],frontier(F[A])) -> 0`.

## Красная граница

Формализация устанавливает геометрический и топологический результат. Она не
отождествляет вычислительное разрешение с физической планковской величиной.

## Проверка

- Основной модуль: `formal/AnisotropicEllipseChamber.lean`.
- Независимый аудит: `formal/AnisotropicEllipseChamberAudit.lean`.
- Запрещённые пропуски: `axiom`, `sorry`, `admit`.
