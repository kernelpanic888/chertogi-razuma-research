# F8C6B. Точные спектральные константы карты

## Задача

F8C6A нашёл точную квадратичную оболочку координатного сдвига. Оставался главный шов: доказать, что её собственные направления реализуются настоящими хордами нелинейного ядра, а не существуют только внутри матрицы.

В F8C6B этот шов закрыт для прямой карты и для обратного восстановления.

## Модель

```text
φ(t) = max(0, 1-|t|)
κ(x,y) = φ(x)φ(y)
Sₐ(x,y) = (x, y + aκ(x,y))
```

Рассматривается `a ≥ 0`. Для обратной оценки дополнительно требуется `a < 1`.

## Точная прямая константа

```text
λ→(a) =
  1 + a + a² + a√(a²+2a+2)

C→(a) = √λ→(a)
```

Для всех точек `p,q`:

```text
d(Sₐp,Sₐq) ≤ C→(a)·d(p,q).
```

Более того, `C→(a)` минимальна:

```text
[∀p q, d(Sₐp,Sₐq) ≤ C·d(p,q)]
  ↔
[C→(a) ≤ C]
```

при `C ≥ 0`.

## Почему нижняя сторона настоящая

Для `a>0` собственное направление спектральной формы задаёт положительные числа `B,A`. Берутся реальные точки

```text
qₜ = (-tB,-tA),    t→0⁺.
```

Они лежат внутри носителя ядра при достаточно малом `t`. Отношение реальных расстояний карты вдоль этих хорд стремится к `C→(a)`. Для каждого меньшего `C` Lean строит конкретное положительное `t), нарушающее заявленную оценку.

## Точная обратная константа

Вводится

```text
β(a) = a/(1-a).
```

Тогда

```text
λ←(a) =
  1 + β + β² + β√(β²+2β+2)

C←(a) = √λ←(a).
```

Lean также доказывает эквивалентную формулу без вспомогательного параметра:

```text
λ←(a) =
  [1-a+a²+a√(a²-2a+2)] / (1-a)².
```

Для `0≤a<1`:

```text
d(p,q) ≤ C←(a)·d(Sₐp,Sₐq).
```

И эта константа тоже минимальна:

```text
[∀p q, d(p,q) ≤ C·d(Sₐp,Sₐq)]
  ↔
[C←(a) ≤ C].
```

Нижняя сторона реализуется хордами из положительного квадранта:

```text
qₜ = (tx,ty),    t→0⁺.
```

Они приближают собственное направление обратной спектральной формы и фиксируют максимальное восстановительное растяжение.

## Двухсторонний результат

```text
[1/C←(a)]·d(p,q)
  ≤ d(Sₐp,Sₐq)
  ≤ C→(a)·d(p,q).
```

Это точные глобальные стороны для данной карты и данной евклидовой метрики. Прежние оценки `1+√2a` и `1/(1-√2a)` остаются корректными, но больше не являются финальными константами камеры.

## Что проверено

- Прямая спектральная оценка перенесена с матрицы на реальные расстояния карты.
- Построены реальные отрицательные хорды, доказывающие точность прямой константы.
- Получена обратная спектральная оценка при `0≤a<1`.
- Построены реальные положительные хорды, доказывающие точность обратной константы.
- Закрытая формула `λ←(a)` доказана в Lean.
- Независимый аудит не использует `axiom`, `sorry` или `admit`.

## Красная граница

Теоремы относятся к авторской математической модели внутреннего сдвига. Они не устанавливают физический масштаб, не отождествляют `a` с измеренной величиной и не доказывают физическую природу PlanckTouch.
