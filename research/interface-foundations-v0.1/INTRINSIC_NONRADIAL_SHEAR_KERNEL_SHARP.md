# F8C6A. Точная константа ядра и спектральные ворота

## Задача

В F8C5 для ядра внутреннего сдвига

```text
κ(x,y) = φ(x)φ(y),    φ(t) = max(0, 1 - |t|)
```

была доказана глобальная оценка

```text
|κ(p) - κ(q)| ≤ √2 · d(p,q).
```

Одной верхней оценки недостаточно: она не говорит, можно ли заменить `√2` меньшим числом. F8C6A закрывает именно этот разрыв и затем выделяет точную спектральную оболочку координатного сдвига.

## Диагональный пробник

Берём вершину ядра

```text
o = (0,0)
```

и диагональную точку

```text
qₜ = (-t,-t),    0 < t ≤ 1.
```

На этом отрезке:

```text
κ(o) = 1,
κ(qₜ) = (1-t)²,
d(o,qₜ) = √2·t.
```

Поэтому

```text
|κ(o)-κ(qₜ)| / d(o,qₜ)
  = [1-(1-t)²] / (√2·t)
  = (2-t)/√2
  → √2  при t → 0⁺.
```

Это не численная иллюстрация, а семейство точных свидетелей. Для каждого `C < √2` формально строится положительное `t`, при котором

```text
C·d(o,qₜ) < |κ(o)-κ(qₜ)|.
```

## Точная теорема о ядре

Пусть

```text
KernelMetricBound(C) :⇔
  ∀ p q, |κ(p)-κ(q)| ≤ C·d(p,q).
```

Тогда для `C ≥ 0`:

```text
KernelMetricBound(C) ↔ √2 ≤ C.
```

Следовательно, `√2` является наименьшей глобальной метрической константой ядра. Верхняя и нижняя стороны доказаны независимо: верхняя следует из координатной оценки F8C5, нижняя задаётся диагональными пробниками F8C6A.

## Спектральные ворота

Для амплитуды `a ≥ 0` рассмотрена квадратичная форма

```text
Qₐ(x,y) = x² + [a·x + (1+a)·y]².
```

Определена константа

```text
λ₊(a) =
  1 + a + a² + a·√(a² + 2a + 2).
```

Формально доказано:

```text
Qₐ(x,y) ≤ λ₊(a)·(x²+y²)
```

для всех вещественных `x,y`, и никакая меньшая глобальная константа эту форму не ограничивает:

```text
[∀x y, Qₐ(x,y) ≤ C(x²+y²)] ↔ λ₊(a) ≤ C.
```

Точность нижней стороны даёт собственное направление, построенное внутри доказательства. Производные и внешняя спектральная библиотека не требуются.

## Что доказано

- `√2` является точной, а не грубой константой ядра `κ`.
- Дан явный класс диагональных свидетелей для любого меньшего коэффициента.
- `λ₊(a)` является точной квадратичной константой координатной матрицы.
- Все утверждения проверены Lean без `axiom`, `sorry` и `admit`.

## Красная граница

F8C6A ещё не отождествляет `√λ₊(a)` с оптимальной глобальной константой самой нелинейной карты внутреннего сдвига. Для такого вывода нужно отдельно связать спектральное собственное направление с реальными хордами ядра и доказать достижимость или предельную достижимость. Обратная спектральная константа также остаётся следующим формальным срезом.
