# Паспорт F8C7. Предсказательная камера амплитуды

## Статус

Завершено локально. Точная двухсторонняя геометрия преобразована в монотонный параметрический сертификат. Публикация на Sites выполняется отдельно.

## Основные результаты

- `C→(a)` строго возрастает при `a≥0`.
- `C←(a)` строго возрастает при `0≤a<1`.
- `K(a)=C→(a)C←(a)`.
- `K(0)=1`, `K(a)≥1`.
- `K` строго возрастает на `[0,1)`.
- Каждая из функций `C→`, `C←`, `K` инъективна на своей камере.

## Сертификат наблюдения

```text
DistortionObservation(a,F,B)
↔ C→(a)≤F ∧ C←(a)≤B.
```

```text
a ≤ min(F-1,(B-1)/B).
```

## Честная граница

Конечные измерения дают нижние свидетельства для глобальной константы, но не дают глобальную верхнюю оценку без дополнительных условий. Поэтому текущий сертификат принимает `F,B` именно как уже обоснованные глобальные коэффициенты.

4. Добавить абсолютную и относительную погрешность измерения.
