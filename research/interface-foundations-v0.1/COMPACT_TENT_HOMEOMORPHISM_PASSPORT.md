# Паспорт IF-BS-22F-F8B1

## Точка маршрута

`IF-BS-22F-F8B1 / COMPACT TENT PROFILE -> LOCAL CONTROLLED HOMEOMORPHISM`

## Вход

- `phi(x)=max(0,1-|x|)`.
- `H_a(x)=x+a phi(x)`.
- Параметр `0<=a<1`.

## Выход

- `phi` является 1-липшицевой и принимает значения в `[0,1]`.
- `H_a(x)=x` для каждого `|x|>=1`.
- `H_a` строго возрастает и сюръективна.
- `H_a : Real ≃ₜ Real` является homeomorphism.
- `Lip(H_a)<=1+a`.
- `(1-a)d(x,y)<=d(H_a(x),H_a(y))`.
- `Lip(H_a^(-1))<=1/(1-a)`.
- Получен `ControlledEquiv Real Real` с явными прямой и обратной константами.

## Проверяемая формула

`H_a(x)=x+a max(0,1-|x|)`

`|x|>=1 -> H_a(x)=x`

`0<=a<1 -> H_a : Real ≃ₜ Real`.

## Красная граница

Параметризован один локальный шаг. Бесконечная последовательность шагов, её телескопирование и единый двусторонний контроль префиксов пока не выведены.

## Русская вычитка

Локальное изменение не обязано разрывать всё пространство. Треугольный профиль поднимает только внутренность отрезка, оставляет внешнюю прямую неподвижной и сохраняет обратимость ровно пока амплитуда не достигает единицы. Порог `a=1` является геометрической границей: правая ветвь получает нулевой наклон и перестаёт различать точки.
