# F8C12. Направленный blow-up диагонали

## Проблема

Хордовое отношение

```text
d(Sₐp,Sₐq)/d(p,q)
```

не определено на диагонали `p=q`. Компактность ядра F8C11 не устраняет исчезающий знаменатель, поэтому нельзя честно заявить модуль регулярности самого отношения на всём ядре.

## Нормированная хорда

Для `p≠q` обозначим:

```text
r=d(p,q),
uₓ=(pₓ-qₓ)/r,
uᵧ=(pᵧ-qᵧ)/r,
s=(κ(p)-κ(q))/r.
```

Тогда:

```text
uₓ²+uᵧ²=1.
```

Из точной липшицевой константы kernel:

```text
|s|≤√2.
```

Каждая различимая хорда поэтому входит в компактную направленную камеру:

```text
B=S¹×[-√2,√2].
```

## Десингуляризованная величина

Вместо отношения длин вводится квадрат растяжения на blow-up:

```text
Φₐ(u,s)=uₓ²+(uᵧ+a·s)².
```

Это обычный полином, определённый на всей камере, включая предельные направления диагонали.

Lean доказывает точное тождество для каждой `p≠q`:

```text
d(Sₐp,Sₐq)²
=Φₐ(blowUp(p,q))·d(p,q)².
```

Для `p=q` обе стороны итоговой оценки равны нулю.

## Явный модуль регулярности

На product-метрике камеры доказано:

```text
|Φₐ(z)-Φₐ(w)|
≤L₂(a)·d(z,w),
```

где при `a≥0`:

```text
L₂(a)=2+4(1+a)².
```

Оценка использует только:

```text
|uₓ|≤1,
|uᵧ|≤1,
|s|≤√2≤2,
```

и контроль каждой координаты product-расстоянием.

## Конечный глобальный сертификат

F8C11 даёт для любого `δ>0` конечную δ-сеть камеры. F8C12 автоматически строит для неё:

```text
NoisyUpperSampleValid,
DeltaCoverage,
SampleInside,
RegularityCertificate(L₂(a)).
```

F8C9 затем даёт:

```text
Φₐ(z)≤Mnoise+L₂(a)δ.
```

Перенос обратно на исходные хорды:

```text
d(Sₐp,Sₐq)²
≤(Mnoise+L₂(a)δ)d(p,q)²
```

для всех `p,q`, включая диагональ.

## Значение результата

Сингулярность была не физической границей и не потерей данных. Она возникала из неудачной координаты с делением на длину хорды. Направленный blow-up сохраняет направление предельного касания и превращает задачу в непрерывную компактную геометрию.

## Красная граница

Камера `S¹×[-√2,√2]` является безопасным расширением: Lean доказывает, что каждая хорда входит в неё, но не утверждает, что каждая её точка реализуется реальной хордой kernel. Поэтому конечный сертификат глобален, но может быть консервативнее точной спектральной константы F8C6B. Обратный квадрат растяжения ещё не перенесён на отдельную blow-up-камеру.
