# F8C10. Компактное сведение пространства хорд

## Задача

F8C9 дал условный переход от конечной шумовой δ-сети к глобальной верхней границе, но всё пространство хорд неограниченно. F8C10 раскладывает его на три области, для которых нужны разные аргументы:

```text
неподвижное поле
+ дальние хорды
+ короткое активное ядро.
```

## Локальное смещение

Для внутреннего сдвига `Sₐ` при `a≥0` доказано:

```text
d(Sₐp,p)≤a.
```

Отсюда для любой пары:

```text
d(Sₐp,Sₐq)≤d(p,q)+2a,
d(p,q)≤d(Sₐp,Sₐq)+2a.
```

## Неподвижное поле

Точный носитель изменения равен квадрату:

```text
K=[-1,1]².
```

Если оба конца хорды лежат вне `K`, то:

```text
Sₐp=p,
Sₐq=q,
d(Sₐp,Sₐq)=d(p,q).
```

Коэффициент этой области точно равен `1`.

## Дальнее поле

Для `ρ>0`, если входная хорда длиннее порога,

```text
ρ≤d(p,q),
```

то:

```text
d(Sₐp,Sₐq)
≤(1+2a/ρ)d(p,q).
```

Для обратного чтения, если длиннее выходная хорда,

```text
ρ≤d(Sₐp,Sₐq),
```

то:

```text
d(p,q)
≤(1+2a/ρ)d(Sₐp,Sₐq).
```

## Короткое активное ядро

Прямое ядро состоит из пар, у которых хотя бы один конец лежит в `K`, а входная длина не превосходит `ρ`:

```text
K→(ρ)={ (p,q) | d(p,q)≤ρ ∧ (p∈K ∨ q∈K) }.
```

Так как каждая точка `K` находится не дальше `√2` от начала, обе конечные точки такой пары лежат в шаре радиуса:

```text
R→=√2+ρ.
```

Обратное ядро использует короткую выходную хорду:

```text
K←(a,ρ)=
{ (p,q) | d(Sₐp,Sₐq)≤ρ ∧ (p∈K ∨ q∈K) }.
```

Из двухсторонней оценки смещения обе точки лежат в шаре радиуса:

```text
R←=√2+ρ+2a.
```

Произведение двух замкнутых шаров является компактным контейнером для соответствующего ядра.

## Глобальная сборка

Пусть на прямом ядре уже доказан локальный коэффициент `Ccore→`. Тогда F8C10 доказывает:

```text
C→≤max(1,1+2a/ρ,Ccore→).
```

Аналогично для обратного ядра:

```text
C←≤max(1,1+2a/ρ,Ccore←).
```

Это строгая редукция глобальной задачи к ограниченной области плюс две явные внешние оценки.

## Красная граница

В этом срезе доказано включение ядер в компактные контейнеры. Ещё не заявлено, что сами предикатные ядра замкнуты, что на них извлечена конечная δ-сеть или что отношение хорд имеет доказанный модуль регулярности возле диагонали. Эти обязательства переходят в F8C11.
