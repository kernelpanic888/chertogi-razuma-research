# F8C11. Замкнутое ядро и конечная δ-сеть

## Задача

F8C10 поместил короткие активные хорды в компактные контейнеры. Одного включения недостаточно: произвольное подмножество компакта может не быть компактным. F8C11 закрывает именно этот разрыв.

## Прямое ядро

```text
K→(ρ)=
{(p,q) | d(p,q)≤ρ}
∩
({p∈K}∪{q∈K}).
```

Первая часть замкнута как подуровень непрерывной функции расстояния. Вторая часть замкнута как объединение двух прообразов замкнутого точного carrier `K=[-1,1]²`.

Поэтому:

```text
K→(ρ) closed.
```

При `ρ≥0` F8C10 даёт:

```text
K→(ρ)⊆B(0,√2+ρ)².
```

Замкнутое подмножество компактного контейнера компактно:

```text
K→(ρ) compact.
```

## Обратное ядро

При `a≥0` карта `Sₐ` липшицева, следовательно, непрерывна. Поэтому выходное расстояние

```text
(p,q)↦d(Sₐp,Sₐq)
```

непрерывно. Тем же аргументом:

```text
K←(a,ρ) closed.
```

Вместе с контейнером F8C10:

```text
K←(a,ρ)⊆B(0,√2+ρ+2a)²
```

получаем:

```text
K←(a,ρ) compact.
```

## Конечная δ-сеть

Для любого компактного метрического множества `D` и любого `δ>0` Lean извлекает конечное множество центров:

```text
∃Γδ⊆D,
Finite(Γδ)
∧
∀x∈D, ∃γ∈Γδ, d(x,γ)<δ.
```

Это стандартное следствие полной ограниченности компакта, но в F8C11 оно экспортировано как отдельный контракт `FiniteMetricDeltaNet`.

## Буквальный мост к F8C9

Каждый центр превращается в точное чтение:

```text
reading(γ)=
{point=γ,
 measured=f(γ),
 error=0}.
```

Lean доказывает существование конечного списка, для которого одновременно выполнены:

```text
NoisyUpperSampleValid,
DeltaCoverage,
SampleInside.
```

Если отдельно предъявлен модуль регулярности `L`, F8C9 немедленно даёт:

```text
∀x∈D,
f(x)≤Mnoise+Lδ.
```

## Что изменилось

В F8C9 конечное покрытие неограниченного пространства было открытым обязательством. После F8C10-F8C11 конечная сетка для обоих релевантных ядер существует как теорема. Неограниченное дополнение уже закрыто аналитическими оценками.

## Красная граница

Компактность не создаёт модуль регулярности автоматически для хордового отношения с делением на `d(p,q)`. Возле диагонали знаменатель стремится к нулю. Следующий срез должен либо доказать продолжение отношения, либо перейти к непрерывной десингуляризованной величине.
