# Паспорт F8C6A. Точная константа ядра

## Статус

Завершено локально. Основной файл и независимый аудит должны компилироваться без доказательных заглушек. Публичная публикация этого среза выполняется только по отдельной команде.

## Полученный результат

- Точная глобальная константа ядра: `√2`.
- Диагональный пробник: `qₜ=(-t,-t)`, `t→0⁺`.
- Точное отношение: `[1-(1-t)²]/(√2t)=(2-t)/√2→√2`.
- Точная спектральная квадратичная константа:

```text
λ₊(a)=1+a+a²+a√(a²+2a+2).
```

- Доказан критерий минимальности `λ₊(a)` для соответствующей квадратичной формы.

## Граница утверждения

`λ₊(a)` пока является точной константой алгебраической спектральной оболочки. Её равенство оптимальной константе нелинейной карты не заявлено. Физическая интерпретация и физический масштаб не заявлены.

1. Перенести точную квадратичную оболочку на хорды карты `Sₐ`.

3. Построить семейство реальных хорд ядра, приближающих собственное направление.
4. Проверить, достигается ли `√λ₊(a)` самой картой или спектральная оболочка остаётся строгой.
5. Отдельно построить обратную спектральную камеру и сравнить её с текущей константой `1/(1-√2a)`.
