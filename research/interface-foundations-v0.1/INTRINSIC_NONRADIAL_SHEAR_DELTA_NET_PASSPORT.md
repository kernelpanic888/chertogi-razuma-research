# Паспорт F8C9. Шумовая δ-сеть

## Статус

Завершено локально. Доказан условный, но полный переход от конечной шумовой сетки к глобальной верхней границе.

## Контракт

```text
coverage:
∀x∈D, ∃s∈sample, d(x,s)≤δ
```

```text
regularity:
|f(x)-f(s)|≤L·d(x,s)
```

```text
measurement:
|m(s)-f(s)|≤ε(s).
```

## Результат

```text
f(x)≤Mnoise+Lδ.
```

Для карты:

```text
C→(a)≤M→+L→δ→
C←(a)≤M←+L←δ←.
```

```text
a≤min(Fnet-1,(Bnet-1)/Bnet).
```

## Красная граница

Существование конечного покрытия всего неограниченного пространства хорд не заявлено. Сертификат становится практически конечным после доказанного разложения области.

F8C10 / Компактное разложение пространства хорд.

1. Выделить компактную пару квадратов вокруг точного носителя сдвига.
2. Доказать аналитическую оценку для дальних хорд.
3. Отделить окрестность диагонали и её локальный модуль.
4. Свести поиск глобального максимума к компактному ядру плюс явные внешние границы.
5. Применить F8C9 только к действительно конечнопокрываемой области.
6. Провести независимый аудит и нарисовать карту «ядро / дальнее поле / диагональ».
