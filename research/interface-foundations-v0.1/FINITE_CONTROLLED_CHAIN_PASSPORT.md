# Паспорт IF-BS-22F-F5

## Узел

Конечные цепи и ограниченные префиксы.

## Конечная цепь

- Вход: список `F_0,...,F_(m-1)` controlled-самопереносов.
- Прямой коэффициент: `P_m=prod_(i<m)L_i`.
- Обратный коэффициент: произведение всех обратных констант.
- Ошибка: `d_H(F_chain[K_n],F_chain[I])≤P_m e_n`.
- Интерфейс остаётся actual frontier.
- При фиксированной цепи ошибка стремится к нулю.

## Бесконечная последовательность префиксов

- `P_n=prod_(i<n)L_i`.
- Условие контроля: существует `C`, для которого `P_n≤C` при всех `n`.
- Следствие: `P_n e_n→0`.
- Следствие: ошибка `n`-го carrier относительно его движущегося actual frontier
  стремится к нулю.

## Красная граница

Движущиеся фронтиры пока не доказаны сходящимися к одному множеству. Для этого
нужен отдельный Cauchy-критерий самих преобразований или их образов.
