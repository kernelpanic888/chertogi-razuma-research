# F8C9. Сертификат δ-сети и глобальная верхняя граница

## Задача

F8C8 доказал, что конечные хорды дают только нижние свидетельства. Чтобы конечная сетка могла дать верхнюю границу на всей области, необходимы два дополнительных сертификата:

```text
покрытие области радиусом δ
и модуль регулярности L.
```

F8C9 формализует этот переход без скрытых предпосылок.

## Шумовое верхнее чтение

Каждая запись содержит:

```text
(x,m,ε),
```

где `x` — точка области параметров, `m` — измеренное значение функции `f`, а `ε` — абсолютная ошибка.

Валидность:

```text
ε≥0
|m-f(x)|≤ε.
```

Поэтому:

```text
f(x)≤m+ε.
```

Для конечного списка определяется:

```text
Mnoise=max(0,m₁+ε₁,…,mₙ+εₙ).
```

## δ-покрытие

Сетка покрывает область `D`, если:

```text
∀x∈D, ∃s∈sample:
  d(x,s)≤δ.
```

## Сертификат регулярности

Функция должна удовлетворять на парах «точка области — узел сетки»:

```text
|f(x)-f(s)|≤L·d(x,s).
```

Здесь `L` не угадывается по данным. Он является отдельным доказанным или обоснованным входом сертификата.

## Главная теорема

Lean доказывает:

```text
∀x∈D,
f(x)≤Mnoise+Lδ.
```

Доказательство использует ближайший узел сетки:

```text
f(x)
≤f(s)+L·d(x,s)
≤Mnoise+Lδ.
```

## Пространство хорд

Для прямой стороны вводится пространство различимых хорд:

```text
Chord={(p,q) | p≠q}.
```

На нём:

```text
r→(p,q)=d(Sₐp,Sₐq)/d(p,q).
```

Если шумовая сетка покрывает всё заявленное пространство хорд и имеет сертификат регулярности, то:

```text
d(Sₐp,Sₐq)
≤(M→+L→δ→)d(p,q).
```

Следовательно:

```text
C→(a)≤M→+L→δ→
```

и

```text
a≤M→+L→δ→-1.
```

## Обратная сторона

Для хорд с различимыми образами:

```text
r←(p,q)=d(p,q)/d(Sₐp,Sₐq).
```

При `0≤a<1` доказана инъективность карты, поэтому каждая различимая входная хорда имеет различимый образ.

Из обратной шумовой δ-сети:

```text
C←(a)≤M←+L←δ←.
```

## Двухсторонний сеточный сертификат

```text
Fnet=M→+L→δ→
Bnet=M←+L←δ←.
```

Тогда:

```text
a≤min(Fnet-1,(Bnet-1)/Bnet).
```

Это уже глобальный вывод, но только при выполнении обоих явных контрактов покрытия и регулярности.

## Красная граница

Теорема не утверждает, что конечная δ-сеть всего неограниченного пространства хорд автоматически существует. Для практического конечного сертификата нужно разложить пространство:

```text
компактное релевантное ядро
+ аналитически контролируемое дополнение
+ отдельная окрестность диагонали.
```

Такое разложение является следующим формальным срезом.
