# P1 AGGREGATE COUNTER PROTOCOL

**Версия:** `P1-AC-01`  
**Статус:** verified research candidate / not deployed  
**Связь с публичным сайтом:** отсутствует; `P0` не изменяется до отдельного решения о развёртывании

## Цель

Получить минимальную статистику событий без регистрации, профиля посетителя и утверждения об уникальных людях. Система считает только разрешённые события по серверному UTC-дню.

## Допустимый вход

```text
PublicIngress := (method, route, bodyBytes)
method        := POST
bodyBytes     := 0
route         := /e/page-view
              |  /e/reader-open
              |  /e/language-switch
              |  /e/support-open
day           := UTC-day(serverClock)
```

Query string, тело запроса и произвольное имя события запрещены. День не принимается от клиента.

## Запрещённое состояние

```text
raw IP
User-Agent
full referrer
cookie value
visitor ID / fingerprint
account / email
request body
per-person event history
unique visitors estimate
```

Эти поля могут существовать на транспортном слое провайдера, но не входят в авторский контракт, безопасное событие, состояние счётчика или его выход.

## Сохраняемое состояние

```text
SafeEvent := (serverDay, EventKind)
Counter   := Map serverDay (Map EventKind SaturatingNat)
```

Белый список содержит четыре вида событий. Хранится не более `35` UTC-дней. Каждый счётчик насыщается на `2_147_483_647` и не переполняется. Число ключей состояния ограничено сверху: `35 * 4`.

## Основной инвариант

Для любых двух входов с одинаковыми `(method, route, bodyBytes)` и любыми различными метаданными:

```text
sanitize(day, requestA) = sanitize(day, requestB)
process(day, state, requestA) = process(day, state, requestB)
```

Это невлияние метаданных, а не обещание анонимности всего интернета: провайдер и сетевые журналы остаются внешней границей.

## Слепой тест `P1-AC-BLIND-01`

Чёрноящичный процесс получает синтетический поток из `768` запросов за `50` дней. В запросы внедряются уникальные IP, User-Agent, referrer, cookies и visitor IDs, а также неверные методы, тела, query strings и неизвестные маршруты. Независимый harness знает только зафиксированный контракт и сравнивает итоговый агрегат с собственным oracle.

Тест проходит только если:

- принят ровно ожидаемый набор событий;
- сохранено не более `35` дней;
- выход совпадает с независимым oracle;
- ни один запрещённый маркер не присутствует в выходе;
- кандидат ничего не пишет в stderr;
- публичный `P0` не изменён.

## Красная граница

Тест доказывает свойства данного ядра и его интерфейса. Он не доказывает отсутствие журналирования у хостинга, операционной системы или будущего сетевого адаптера. До отдельного живого теста `P1` не называется развёрнутой защитой и не включается на сайт.

**Следующий шаг по паспорту:** спроектировать минимальный сетевой адаптер, проверить границу провайдера и только после отдельного решения рассматривать развёртывание.
