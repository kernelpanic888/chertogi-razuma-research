# P1 NETWORK ADAPTER PROTOCOL

**Идентификатор:** `P1-NA-01`  
**Статус:** implementation candidate / not deployed  
**Зависимость:** проверенное ядро `P1-AC-01`  
**Публичный P0:** не изменяется

## Задача

Соединить будущую публичную страницу с агрегатным счётчиком, не создавая идентичность посетителя и не передавая ядру сетевые метаданные.

## Минимальная способность адаптера

Адаптер может читать только:

```text
request.method
request.url
request.body == null
serverClock
configuredExpectedOrigin
aggregateState
```

Он не читает `headers`, `cf`, IP, User-Agent, referrer, cookies, тело или идентификатор посетителя. Допускается только HTTPS URL ожидаемого origin без credentials, query и fragment. Маршрут проверяется белым списком ядра.

## Лемма неразличимости актора

Если политика видит только `ObservableRequest`, то человек и бот с одинаковым `ObservableRequest` получают одинаковое решение:

```text
observable(humanRequest) = observable(botRequest)
=> decision(humanRequest) = decision(botRequest)
```

Следствие: без идентификатора, секрета или внешней аттестации нельзя одновременно гарантировать приватность и достоверно отделять человеческие события от синтетических. Поэтому система считает события, а не людей.

## Ограничение ущерба

Вместо персонального rate limit используется общий дневной бюджет. После достижения `100_000` принятых событий за UTC-день адаптер возвращает `429` и не меняет состояние. Бюджет настраивается и проверяется до перехода счётчика.

Это ограничивает вычисление и рост счётчика, но не защищает качество статистики: атакующий может исчерпать общий бюджет или исказить агрегат. Статистика остаётся шумным наблюдением.

## Ответ

Принятое событие возвращает только статус `204`. Ответ не содержит тела, идентификатора, счётчика, cookie или CORS-разрешения. Ошибка возвращает только фиксированный статус и локальную машинную причину для теста; сетевой wrapper не обязан публиковать причину.

## Выключатель

`P1` является отдельной способностью. Если binding состояния отсутствует, конфигурация неверна или эксперимент отключён, маршрут аналитики не монтируется, а сайт продолжает работать как неизменный `P0`.

## Красная граница

Адаптер не контролирует журналы провайдера до входа в авторский runtime. Глобальный бюджет не является доказательством человеческой аудитории и не предотвращает Sybil/spam. До живого теста и явного решения модуль остаётся неразвёрнутым.

**Следующий шаг по паспорту:** проверить capability trap, глобальный бюджет и Lean-лемму неразличимости, затем выпустить отдельный кандидатный паспорт.
