# P1 NETWORK ADAPTER PASSPORT

**Идентификатор:** `P1-NA-01`  
**Статус:** verified research candidate  
**Развёртывание:** нет  
**Публичный P0:** не изменён

## Результат

Построен выключаемый чистый адаптер между будущим сетевым маршрутом и `P1-AC-01`. Адаптер читает только `method`, `url` и признак отсутствующего тела, проверяет ожидаемый HTTPS origin, запрещает credentials/query/fragment, проецирует точный путь в белый список и применяет общий дневной бюджет.

Он не читает заголовки запроса, объект `cf`, IP, User-Agent, referrer, cookies или visitor ID. Принятый переход не создаёт ответного тела, cookie, пользовательского счётчика или идентификатора.

## Формальная граница

Lean-лемма `actor_indistinguishability` доказывает без аксиом:

```text
same observable request
=> same admission decision
```

Скрытая метка `human` или `bot` не может влиять на политику, которой она не дана. Поэтому система без идентификаторов принципиально не может обещать достоверное разделение людей и ботов.

## Ограничение ущерба

`admittedWork(budget, emitted) := min(budget, emitted)` формально ограничено сверху бюджетом. При текущем контракте значение по умолчанию равно `100_000` событий на серверный UTC-день. После исчерпания бюджета состояние не меняется и кандидат возвращает `429`.

Это защита доступности и верхняя граница работы, но не защита качества статистики. Синтетические события могут исказить агрегат или раньше времени исчерпать бюджет.

## Проверки

### Node 25.9.0

`8/8 PASS`:

- минимальная HTTPS-проекция;
- отказ для метода, тела, URL-деталей, чужого origin и неизвестного маршрута;
- capability trap для запрещённых свойств;
- одинаковое решение при разных скрытых метаданных;
- глобальный дневной бюджет;
- неизменность состояния при отказе;
- отсутствие body/headers/cookie/count в результате;
- fail-closed для неверной конфигурации.

### Lean 4.32.1

- `actor_indistinguishability`: без аксиом;
- `admitted_work_is_globally_bounded`: только `[propext]`;
- `accepted_increment_respects_budget`: без аксиом;
- компиляция завершена с кодом `0`.

## Что остаётся открытым

Не проверены реальный handler, binding постоянного агрегатного состояния, атомарность конкурентных инкрементов, провайдерские журналы, доступность маршрута, поведение при распределённых повторах и живой выключатель. Пока эти свойства не доказаны, адаптер не развёртывается.

## Решение о продукте

Для честной статистики без регистрации интерфейс должен показывать только «события» или «открытия», никогда «людей» или «уникальных посетителей». Устойчивость к ботам может быть отдельной вероятностной оценкой, но не должна незаметно возвращать идентификацию.

**Следующий шаг по паспорту:** спроектировать атомарное агрегатное хранилище как отдельную способность и доказать, что его отсутствие автоматически оставляет сайт в режиме `P0`.
