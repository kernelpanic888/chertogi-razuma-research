## Что теперь связано с физикой

Двухисходный инструмент измерения:

```
rho = diag(p, 1-p)
Ks = diag(1, lambda)
Kf = diag(0, sqrt(1-lambda^2))
Ks† Ks + Kf† Kf = I
```

Реализация: системный кубит в диагональной смеси; вспомогательный кубит в 0;
контролируемый Ry(2 arccos lambda) на вспомогательном кубите, управляемый
системным; затем измерение обоих в Z-базисе. Вспомогательный 0 означает
успех фильтра, 1 — отказ. Статистика учитывает **все** запуски.

Сравниваются три независимых пути вычисления:

1. Нативный Lean-executable: точные целые веса, общий знаменатель и
   условная вероятность. Импортирует неизменённое ядро опубликованного ER-01.
2. Python: матрица плотности 4×4, унитарная операция U rho U† и правило Борна.
   Численный расчёт с плавающей точкой; симулятор не является устройством.
3. Классический контроль: Bernoulli-источник и пропускание состояния 1 с
   вероятностью lambda². Независимый поток случайных чисел.

Нынешний диагональный вход имеет классическое воспроизведение. Совпадение
не свидетельствует о квантовом преимуществе, когерентности, горизонте или
машине времени. Эти свойства в текущем опыте не проверяются.

## Формальные границы

Семь добавленных теорем Lean доказывают полноту весов, согласованность
успешной ветви с прежним ядром, ограниченность отказа, отсутствие отказа
для прозрачного фильтра/чистого 0 и отсутствие posterior при нулевом успехе.
Полнота комплексных матриц Крауса и унитарное расширение здесь проверяются
независимым численным расчётом, а не выдаются за теоремы Lean.

Проверены все 10201 пары целых процентов p, lambda. Рациональные вероятности
классического контроля совпали с Lean точно. Максимальная ошибка матричного
расчёта: 2.220446049250313e-16. Отдельно проверена экспортируемая
декомпозиция controlled-Ry для 101 значения lambda. Аудит аксиом сохранён в
verification/axioms.log; отчёт и хеши — verification/report.json.

## Счётчики и статистика

Протокол выдаёт схемы OpenQASM 2 для двух подготовок и отображение битов.
Это спецификация, не отправленное квантовое задание. Для каждого запуска
подготовка 0 случайно выбирается с вероятностью p; иначе выбирается 1.
Фиксированное распределение shots между подготовками — другой дизайн,
не поддерживаемый текущим анализом интервалов.

Формат импорта:

```json
{
  "schema": "ER01-COUNTS/1",
  "pPercent": 50,
  "lambdaPercent": 50,
  "shots": 10000,
  "samplingDesign": "iid-mixture",
  "source": "устройство, задание, дата и параметры",
  "counts": {
    "success0": 5000,
    "success1": 1250,
    "failure0": 0,
    "failure1": 3750
  }
}
```

**Числа выше — синтетический пример идеального ожидания, не данные устройства.**
Импорт проверяет схему, целые неотрицательные счётчики, сумму и параметры;
происхождение остаётся непроверенным. Нельзя импортировать только успешные
запуски с выдачей их числа за общее. Для контроля физического опыта нужны
исходные результаты всех запусков, подготовка, сведения об устройстве,
компиляции схем, калибровке и дизайне выборки. Импорт счётчиков сам по себе
не удостоверяет эти сведения.

Интервалы Уилсона 95% показывают выборочную неопределённость при iid-запусках;
они не учитывают систематический шум и не являются автоматическим тестом
истинности физической гипотезы. Нулевая выборка успехов означает отсутствие
оценки условной доли, а не условную вероятность ноль.

## v0.2 — сеть состояний и интерфейсов

Вершины — входное и условные состояния системы, затем состояния классических
регистров записи. Рёбра — интерфейсы с операциями Ks, Kf, Π0, Π1. Σ обозначает
семейство фильтрующих интерфейсов. Веса рёбер и карты чтения экспортирует Lean.
На стрелке — условная вероятность; совместный вес пути доступен по нажатию
на подпись стрелки. Под вершиной — доля от всех запусков.

Добавлены десять теорем: монотонность ранга вдоль интерфейсов и путей,
отсутствие возврата к входу из остальных вершин, нулевой вес F0, сохранение
веса при чтении каждой ветви, полнота среза {Ks,Kf}, отключение успешного
интерфейса при нулевом весе, совпадение грубых и различие подробных записей.
Отсутствие возврата следует из структуры выбранного DAG; оно не доказывает
запрет физических обратных процессов. Ранг — слой графа, не время.

Нажатие вершины подсвечивает достижимые состояния по рёбрам с положительным
весом. Переключение чтения сохраняет различные вершины, но меняет доступные
наблюдателю метки. Геометрическое расположение вершин условно; метрика,
пространство-время и физический горизонт не определены.
